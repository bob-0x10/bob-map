# processor
Collect and Compute log to get attendance and position information

## How to use

1. Run ``setup.sh`` to make your system environment ready.
1. Edit ``collector_config.ini`` and ``engine_config.ini`` so processor work on your environment.
1. Run ``collector.sh`` and ``engine.sh``.
