# provider
Provide information to front-end(Restful-api server) 

## How to use

1. Run ``dependencies.sh`` so your service ready.
1. Edit ``application.properties`` so provider work on your environment.
1. Run ``sudo java -jar attend.jar`` so your spring boot server-on.
1. Check ``127.0.0.1:{port}`` to check your server on(default port:8088)
