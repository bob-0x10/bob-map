# provider
프런트엔드에 정보를 제공하는 Restful-api 서버

## 사용방법

1. ``dependencies.sh``를 실행하여 시스템 환경을 준비하십시오.
1. provider가 당신의 환경에서 작동하도록 ``application.properties``를 편집하십시오.
1. ``sudo java -jar attend.jar``를 실행하십시오.
1. 1. ``127.0.0.1:{포트}``를 확인하여 서버를 확인합니다(기본 포트:8088).
